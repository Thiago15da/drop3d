## Contenido y límites

Servicios documentados: impresión bajo demanda, prototipos visuales, maquetas y merchandising. Materiales publicados por la empresa: PLA, PETG, ABS, TPU. Se evitan garantías de resistencia, seguridad, plazos o precios sin evaluación técnica.

Contacto: el brief valida datos y prepara una vista previa. Un segundo enlace abre WhatsApp con el mensaje; no se envía automáticamente. No se reciben archivos ni se almacenan datos. Muestrario visual conceptual, no simulación física.

## Desarrollo

`npm run build` genera `dist/` y comprueba páginas y recursos. GitHub Pages se publica con `.github/workflows/pages.yml`. Seleccionar GitHub Actions como origen en Settings > Pages. Todas las rutas son relativas y cada página puede recargarse directamente. La demo pública usa noindex; no cambia drop3d.com.py.

Fuentes locales: Geist, SIL OFL (`assets/fonts/Geist-OFL.txt`). Imágenes WebP de 720 y 1440 px.
